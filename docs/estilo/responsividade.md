# Responsividade — Breakpoints e Regras

## Breakpoints
- Mobile: < 768px (base — mobile first)
- Tablet: 768–1024px
- Desktop: > 1024px

## Regras por elemento
| Elemento | Mobile | Desktop |
|---|---|---|
| Navbar | hambúrguer, menu fullscreen | links inline |
| Hero | coluna única (terminal → foto → botões) | 2 colunas (terminal+texto | foto) |
| Skills grid | 2 col min | auto-fit 160px+ |
| Projects grid | 1 col | 2–3 col |
| Modal | fullscreen slide-up | centralizado max-w 720px |
| Fonte terminal | 13px | 15px |

## Teste obrigatório
DevTools: 360px, 768px, 1280px, 1920px — nada pode quebrar ou rolar
horizontal em nenhum deles.
